# perft_suite.txt - reference node counts for ./perft
#
# Format (both accepted):
#   FEN;depth;expected
#   FEN ;D1 n ;D2 n ;D3 n ...
# Blank lines and lines whose first non-space character is '#' are skipped.
#
# ./perft perft_suite.txt          runs D1-D4 (DEFAULT_DEPTH 4, ~11M nodes, seconds)
# ./perft -d 5 perft_suite.txt     runs D1-D5 (~483M nodes, MINUTES on an 8 GB M1)
# ./perft -d 3 --check perft_suite.txt   adds reconcile() at every make and unmake
# ./perft --make all -d 3 perft_suite.txt   cross-checks ff_move / do_move / do_move_dp
#
# The six positions below are the canonical Chess Programming Wiki perft suite.
# D6/D7 lines are commented out on purpose: startpos D6 is 119M nodes and
# position 3 D7 is 178M nodes, which is more than this machine should be asked
# for in an automated gate. Uncomment deliberately, never in an apply-then-gate loop.
